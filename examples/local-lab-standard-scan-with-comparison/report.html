  2. Validate Origin against a strict allow-list; never reflect arbitrary origins with credentials. (DOXA-002)
  3. Remove the file from the web root, deny access in the web-server configuration and rotate any credentials it contained. (DOXA-003, DOXA-004, DOXA-017)
  4. Remove secrets from client-side code, rotate any value that was real, and keep credentials on the server side. For public client keys, restrict them (referrer, scope, quota). (DOXA-005, DOXA-006, DOXA-010, DOXA-028, DOXA-029)
  5. Set the HttpOnly attribute on cookies that JavaScript does not need. (DOXA-007)
  6. Disable directory indexing (Options -Indexes, autoindex off) and review exposed files. (DOXA-008)
  7. Serve the API over HTTPS only and prefer token-based authentication. (DOXA-009)
  8. Review the flagged locations. Avoid innerHTML/document.write/eval with untrusted data; use textContent or a sanitiser and add a Content-Security-Policy. (DOXA-011)
  9. Require authentication and enforce object-level authorization on the server for every non-public endpoint. (DOXA-012, DOXA-013)
  10. Deploy a valid TLS certificate, enable HTTPS and redirect HTTP to HTTPS. (DOXA-014)
  11. Return generic error messages in production and log details server-side. (DOXA-015, DOXA-016)
  12. Restrict API documentation to authenticated or internal users where appropriate. (DOXA-018)
  13. Send X-Content-Type-Options: nosniff on all API responses. (DOXA-019)
  14. Set SameSite=Lax or Strict (None only with Secure when required). (DOXA-020)
  15. Disable introspection in production or restrict it to authenticated developers. (DOXA-021)
  16. Disable TRACE (e.g. TraceEnable off). (DOXA-022)
  17. Do not deploy source maps to production, or restrict them to authenticated developers. (DOXA-023)
  18. Define a restrictive Content-Security-Policy (avoid unsafe-inline/unsafe-eval). (DOXA-024)
  19. Send X-Content-Type-Options: nosniff on all responses. (DOXA-025)
  20. Send X-Frame-Options: DENY (or SAMEORIGIN) or a CSP frame-ancestors directive. (DOXA-026)
