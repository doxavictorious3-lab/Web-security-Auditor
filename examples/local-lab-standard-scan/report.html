10. Remediation recommendations

  1. Validate Origin against a strict allow-list; never reflect arbitrary origins with credentials. (DOXA-001)
  2. Remove the file from the web root, deny access in the web-server configuration and rotate any credentials it contained. (DOXA-002, DOXA-003, DOXA-007)

  5. Deploy a valid TLS certificate, enable HTTPS and redirect HTTP to HTTPS. (DOXA-006)
  6. Set SameSite=Lax or Strict (None only with Secure when required). (DOXA-008)
  7. Disable TRACE (e.g. TraceEnable off). (DOXA-009)
  8. Define a restrictive Content-Security-Policy (avoid unsafe-inline/unsafe-eval). (DOXA-010)
  9. Send X-Content-Type-Options: nosniff on all responses. (DOXA-011)
  10. Send X-Frame-Options: DENY (or SAMEORIGIN) or a CSP frame-ancestors directive. (DOXA-012)
  11. Disable unused HTTP methods and require authentication for write methods. (DOXA-013)
  12. Remove or genericise version banners (e.g. ServerTokens Prod, server_tokens off, expose_php=Off). (DOXA-014, DOXA-015)
  13. Do not rely on robots.txt to hide content; protect sensitive paths with authentication and remove revealing entries. (DOXA-016)
